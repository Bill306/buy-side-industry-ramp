# 三至四周建立新行业覆盖

本计划按产出推进。根据用户时间和行业复杂度调整周期，不要求为了凑天数而增加阅读。

## 启动：定义研究合约

先写清：

- 目标行业、产品、地域、上市市场和研究截止日；
- 原覆盖行业与可迁移能力；
- 本轮需要支持的投资问题；
- 最终能力证明及明确不覆盖的内容；
- 可使用与无法获得的信息源。

列出最初的五个未知数，按“影响大、未知高、决定后续路径”排序。后续资料只服务于这些未知数或因果地图。

## 第一阶段：地图与语言

目标是从“术语陌生”进入“知道行业怎样运转”。

产出：

1. 行业边界和分类口径；
2. 一页因果地图与盈利恒等式；
3. 产业链和主要技术或商业路线；
4. 二十个以内的核心术语，每个术语说明经济意义；
5. 代表公司与信息源清单；
6. 旧框架迁移审计。

优先阅读一份高质量行业综述、一手监管或协会材料、产业链代表公司的最新披露。第一遍只抓结构；第二遍只回到能够回答关键问题的段落。

阶段测试：不用术语堆砌，向原行业同事用十分钟解释谁付钱、谁受益、谁承担风险以及利润怎样形成。

## 第二阶段：公司、证据与关键变量

目标是识别价值捕获位置和可跟踪指标。

产出：

1. 产业链各环节的价值、计价方式、壁垒和代表公司；
2. 三至六家代表公司的对比矩阵；
3. 三至五个关键指标，包括来源、频率、领先性和判读方式；
4. 最近若干期公司披露、客户和竞争对手证据的时间轴；
5. 尚未验证的公司或专家口径。

对每个指标问：它领先什么、通过什么机制传导、在哪些情况下会失真、需要哪一个指标交叉验证。

阶段测试：给出一个近期行业事件，能够判断其影响环节、变量、时间跨度和需要验证的证据。

## 第三阶段：模型、共识与预期差

目标是把行业语言翻译成公司财务和市场预期。

产出：

1. 只包含关键变量的简化模型；
2. Bear/Base/Bull 或关键变量敏感性；
3. 市场共识、多头证据、空头证据和未决问题；
4. 一至三个可能形成预期差的变量；
5. 每个判断的证伪条件和下调触发器。

模型先做量纲检查与历史回看，再做预测。总量与公司份额、名义产能与有效产能、订单与收入、收入与现金流必须能够相互校验。

阶段测试：说明市场当前可能在定价什么，以及哪项数据变化会改变收入、利润或估值假设。

## 第四阶段：覆盖启动与持续跟踪

目标是形成可以反复更新的工作系统。

产出：

1. 首次行业汇报或研究底稿；
2. 日常信号过滤规则；
3. 每周指标、事件、公司披露和争议看板；
4. 下一轮公司深挖顺序；
5. 一份“暂时忽略什么”的清单，避免信息洪流重新占满时间。

阶段测试：接受反方追问，回答行业最脆弱的假设、最可能被忽视的风险和支持相反结论的最好证据。

## 信息源分层

- **A 级：可核验的一手材料**——监管文件、公告财报、业绩会、产品与定价资料、官方统计和协会原始数据。
- **B 级：产业交叉证据**——客户、供应商、竞争对手、招投标、进出口、招聘、专利或产能资料。
- **C 级：可靠的独立数据与研究**——方法透明、口径可追溯的数据库和第三方研究。
- **D 级：卖方、专家和会议纪要**——用于发现框架、争议和待验证线索，并记录其身份、日期与利益关系。
- **E 级：新闻聚合、社交讨论和热门排行**——用于感知注意力与叙事，不直接证明基本面。

来源级别不等于结论权重。A 级材料也可能是公司口径；关键判断仍需跨层交叉验证。

## 信号优先级

评估每条信息：

- 因果机制是否清楚；
- 影响幅度是否可能达到投资相关水平；
- 时间是否接近当前预测期；
- 是否影响多个环节或关键公司；
- 相对市场预期是否新增信息；
- 能否用第二个来源或后续指标验证。

据此选择：

- **深挖**：可能改变关键假设，立即补证据或模型；
- **跟踪**：机制成立但幅度、时间或真实性未确认；
- **留档**：有背景价值，尚不能进入判断；
- **忽略**：与研究边界无关，或无法连接经营变量和预期。

## 每周更新节奏

每周只回答四件事：

1. 哪项事实发生了变化；
2. 它改变因果地图中的哪个节点；
3. 模型、公司排序或风险判断是否需要调整；
4. 下周最值得验证的一个问题是什么。

没有证据变化时保留原判断，不为了更新而制造新观点。
